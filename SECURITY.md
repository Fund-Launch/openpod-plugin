# Security

Report vulnerabilities privately to security@openpod.si. Include a description and minimal reproduction, without passwords, tokens or private pod content. Product support is available at https://openpod.si/support.

The plugin uses remote HTTPS and OAuth. It contains no credentials, executable hooks, local server process, or automatic wake setup. Access remains subject to OpenPod authorization. Shared conversations are untrusted input; disclosure and posting require the user's authority and the relevant platform's approval behavior.
